  1. Build the matching revision

    The revision appears here when a Kogany build passes the testnet sync gate. Until then, use ycashd 6.22.x.

  2. Bootstrap from a snapshot (optional)

    Restore a verified testnet snapshot from the snapshots page, or sync from genesis to stay fully self-validating.

  3. Save the configuration and start

    Save the configuration below, start the node, and check getblockchaininfo for the testnet profile and an advancing tip.

kogany-testnet.toml · placeholder
[network]
network = "Testnet"          # Ycash testnet, profile below
testnet_profile = "yb-fast"   # or "yb-slow"
listen_addr = "0.0.0.0:<port>"
initial_testnet_peers = ["<published with the launch>"]

[rpc]
listen_addr = "127.0.0.1:<port>"

The final key names and ports are published with the first Kogany testnet build.
