Post-quantum addresses

Live on the fast testnet

With the vault upgrade, a Ycash address can be held by a post-quantum key instead of secp256k1: FN-DSA-512 (Falcon) or SLH-DSA, checked by the new opcode OP_CHECKPQSIG (0xc2). The third character names the scheme: tqf… / tqs… on testnet, sqf… / sqs… on mainnet once the upgrade activates there. Vault owners and YED holders are post-quantum from the first block. Existing addresses and the Sapling pool stay classical.

  1. Get the current pre-release

    Download and verify koganyd v1.8.0-ycash.beta2 from the download page, or build its tag. It follows the fast testnet through the Vault activation with ycashd's block hashes.

  2. Bootstrap from a snapshot (optional)

    Restore a verified testnet snapshot from the snapshots page, or sync from genesis to stay fully self-validating.

  3. Save the configuration and start

    Save the configuration below, start the node, and check getblockchaininfo for the testnet profile and an advancing tip.

testnet.toml · fast testnet
[network]
network = "Testnet"   # fast testnet; "TestnetSlow" or "TestnetLegacy" for the shadow forks
listen_addr = "[::]"
initial_testnet_peers = ["fastnet-seed.ycash.team:18833"]

[rpc]
listen_addr = "127.0.0.1:18832"

Ports: fast testnet 18833, RPC 18832; slow testnet 18933 / 18932. No testnet peers are built in, so name a seed. Start with ./koganyd -c testnet.toml start.
