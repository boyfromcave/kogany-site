# 1 · download your platform's archive and the checksums
# every platform's line shows: keep only yours
V=v1.8.0-ycash.beta2
P=linux-x86_64P=linux-aarch64P=macos-aarch64
for f in SHA256SUMS SHA256SUMS.cosign.bundle koganyd_${V}_${P}.tar.gz; do
  curl -fLO https://github.com/boyfromcave/kogany/releases/download/$V/$f
done

# 2 · checksum, cosign signature, build provenance
sha256sum -c SHA256SUMS --ignore-missingsha256sum -c SHA256SUMS --ignore-missingshasum -a 256 -c SHA256SUMS --ignore-missing
cosign verify-blob --bundle SHA256SUMS.cosign.bundle \
  --certificate-identity https://github.com/boyfromcave/kogany/.github/workflows/kogany-release.yml@refs/tags/v1.8.0-ycash.beta2 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
gh attestation verify koganyd_${V}_${P}.tar.gz -R boyfromcave/kogany

# 3 · run on the fast testnet (no testnet peers are built in: name the seed)
tar xzf koganyd_${V}_${P}.tar.gz && cd koganyd_${V}_${P}
printf '[network]\nnetwork = "Testnet"\nlisten_addr = "[::]"\ninitial_testnet_peers = ["fastnet-seed.ycash.team:18833"]\n\n[rpc]\nlisten_addr = "127.0.0.1:18832"\n' > testnet.toml
./koganyd -c testnet.toml start

Expect OK, Verified OK and a passing attestation. koganyd has no wallet: use yewd. Not yet a qualified Ycash node line.

Upgrading from beta2: the first start upgrades the database once (state format 30.2.0 to 30.3.0, a minute or two on mainnet; no RPC until it is done). On the fast testnet, upgrade before the development fund's mandate ends there, at the height the release notes name. rpcversion is 10; the fund donation defaults to 0 % ([mining] ydf = 5 keeps it); explorer nodes set [rpc] insight_explorer = true.

Platforms, ports, source build

No Windows or Intel macOS build. Linux needs glibc 2.39 (Ubuntu 24.04 or newer); its debug info is separate (…debug.tar.gz: put koganyd.debug beside koganyd). Each archive has an SPDX SBOM and a README.txt.

Ports: mainnet 8833 / RPC 8832; fast testnet 18833 / 18832; slow testnet 18933 / 18932. network = "TestnetSlow" or "TestnetLegacy" selects the shadow forks of mainnet.

The cosign signature is keyless: its identity is the tag-push run of kogany-release.yml. Kogany is signed with cosign, not the Ycash release minisign key.

Build from source
git clone https://github.com/boyfromcave/kogany
cd kogany && git checkout v1.8.0-ycash.beta2
cargo build --release --locked -p kogany --bin koganyd --features ycash

Without --features ycash the build is upstream Zakura's Zcash node. Not on crates.io; no installer yet. Earlier: v1.8.0-ycash.beta1 (5 Nov 2026).

Expect Signature and comment signature verified, OK, Verified OK and exit status 0. Back up wallet.dat first; this release speaks RPC contract version 10, and a client that requires exactly 9 must accept 10.

Upgrading from beta2: on the fast testnet every node must run this release before the development fund's mandate ends there, at the height the release notes name (a node upgraded late needs clearbanned). Mining: the fund donation defaults to 0 % (-ydf=5 keeps it). The first start fills the new value-pool index once (about 30 seconds on mainnet; RPC answers -28 until then). A container restoring a snapshot now refuses a data directory left by a failed restore.

Seeds: fastnet-seed, slownet-seed, legacy-seed .ycash.team. The slow and legacy testnets copy mainnet to height 3,079,999: a mainnet-sized sync.

macOS binaries are ad-hoc signed, not notarized: after a browser download run xattr -dr com.apple.quarantine . in the unpacked directory (a curl download is not quarantined). Windows: data directory %APPDATA%\Ycash.

Known limitations: no YED attestor set on any public network, so YED cannot be minted on the fast testnet; z_sendmany's minconf defaults to 10; gettransaction's fee and details[].fee can differ for a Sapling-funded send. All in the release notes.

The 4.5.0-lineage reference node, ycash-dd, has no packages: build its tag vault-params/v6.22.0-beta2 from source.

YecWallet

YecWallet pre-releases

  • pre-release
  • desktop wallet, ycashd built in

The Ycash desktop wallet with the Yellowback tab for YED. It bundles ycashd, so it needs no separate node. macOS Apple silicon is the main build; macOS Intel, Linux and Windows are built on a best-effort basis and may be missing from a release.

Check the download first (macOS)
# in the folder holding the .dmg, SHA256SUMS and SHA256SUMS.minisig from the release page
shasum -a 256 -c --ignore-missing SHA256SUMS
minisign -Vm SHA256SUMS -P RWQYr5PFpiPJAigk86vf89bPYrJCXj5tskgRAPRYFsEXyciZo8dveOGQ

Expect OK next to your .dmg, then Signature and comment signature verified. If either check fails, delete the download.

macOS: opening it the first time

YecWallet is not signed with an Apple Developer ID and not notarized, so macOS cannot say who made it; the project's own signatures above can. Install it by dragging yecwallet onto Applications. The first open shows "yecwallet" Not Opened: click Done (not Move to Trash), then open System Settings → Privacy & Security, scroll to Security, click Open Anyway, confirm, and click Open Anyway once more. Right-click → Open no longer skips this on current macOS. Macs managed by an organization may block the app with no override.

Windows shows a SmartScreen prompt for the same reason: More info → Run anyway.
