Kogany has not had a release. This page says how releases will be published and checked, so you know what a genuine one looks like.

There is no Kogany release yet. A binary, image or package calling itself Kogany is not from this project until it is listed here. Version numbers, dates and signing keys appear on this page first; if this page doesn't show one, it doesn't exist.

Building from source today

Developers can build the integration branch. Kogany needs the ycash cargo feature to speak Ycash: without it, the binary behaves like upstream Zakura on Zcash networks. That feature-off build is used to test that the dormant vault code changes nothing there.

git clone https://github.com/boyfromcave/kogany
cd kogany
git checkout upgrade/vault
cargo build --release --locked --features ycash

Until wave W1 lands, a ycash build won't sync the Ycash chain. For a node that runs today, use ycashd: 6.22.x for the vault upgrade line.

How releases will be published

  • GitHub releases on boyfromcave/kogany: prebuilt binaries, a source tarball and SHA256SUMS.txt.
  • Tag-driven builds. As with ycashd, a release workflow builds from a tag and refuses a tag whose version doesn't match its line or whose upgrade heights are unset.
  • Signed checksums. SHA256SUMS.txt is signed by a maintainer key published here, and each asset carries a build provenance attestation from CI.

Kogany becomes a release line only by explicit sign-off at the end of wave W9. Before that, no Kogany build is a release candidate.

Verifying a release (once one exists)

The check has three parts: the checksum file's signature, each binary against the checksum file, and the CI attestation. The signing tool and public key are announced with the first release. The shape:

# 1. the signature over SHA256SUMS.txt, against the key on this page
# 2. your downloads against SHA256SUMS.txt
sha256sum -c --ignore-missing SHA256SUMS.txt     # macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
# 3. the build provenance
gh attestation verify <binary> --repo boyfromcave/kogany

If any step fails, delete the download and open an issue.
