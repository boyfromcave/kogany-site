Kogany, the Ycash node on Zakura, with the vault network upgrade and the Ycash Yellowback (YED) rule module. Release notes and downloads on GitHub. It follows the previous pre-release, v1.8.0-ycash.beta1 (5 Nov 2026).

Release binaries

The release publishes koganyd for three platforms, each with an SPDX software bill of materials. The Linux builds ship their debug info separately: put koganyd.debug beside koganyd to get file and line numbers in backtraces.

No Windows or Intel macOS build. The Linux builds need glibc 2.39 (Ubuntu 24.04 or newer). The GitHub releases page is the only official channel: a Kogany binary offered anywhere else is not from this project.

Verifying a download

Verification has three parts: your downloads against SHA256SUMS, the cosign signature over SHA256SUMS, and the GitHub build attestation proving the release workflow built each asset from the repository. The cosign signature is keyless: its identity is the tag-push run of kogany-release.yml that built these assets, so a rebuild means a new tag.

Linux x86_64 shown; use your platform's archive
gh release download v1.8.0-ycash.beta2 -R boyfromcave/kogany
sha256sum -c SHA256SUMS --ignore-missing   # macOS: shasum -a 256 -c SHA256SUMS --ignore-missing
cosign verify-blob --bundle SHA256SUMS.cosign.bundle \
  --certificate-identity https://github.com/boyfromcave/kogany/.github/workflows/kogany-release.yml@refs/tags/v1.8.0-ycash.beta2 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
gh attestation verify koganyd_v1.8.0-ycash.beta2_linux-x86_64.tar.gz -R boyfromcave/kogany

Expect OK for each file you downloaded, Verified OK from cosign, and a passing attestation. gh attestation verify also checks an SBOM or SHA256SUMS itself. If any check fails, delete the download and report it.

Kogany pre-releases are signed with cosign, not with the Ycash release minisign key. That key (id 02C923A6C593AF18) signs the mainnet snapshots.

Running on the fast testnet

With no testnet peers built in, name a seed. network = "Testnet" is the fast testnet (testnet-yb-fast); "TestnetSlow" and "TestnetLegacy" select the two shadow forks of mainnet.

testnet.toml
tar xzf koganyd_v1.8.0-ycash.beta2_linux-x86_64.tar.gz && cd koganyd_v1.8.0-ycash.beta2_linux-x86_64
printf '[network]\nnetwork = "Testnet"\nlisten_addr = "[::]"\ninitial_testnet_peers = ["fastnet-seed.ycash.team:18833"]\n\n[rpc]\nlisten_addr = "127.0.0.1:18832"\n' > testnet.toml
./koganyd -c testnet.toml start

Ports: mainnet 8833, RPC 8832; fast testnet 18833 / 18832; slow testnet 18933 / 18932. Each archive's README.txt has the details. koganyd has no wallet: the wallet is yewd, built from source.

Building from source

Build the tag. koganyd is the kogany package's ycash build; without the feature, the build gives upstream Zakura's Zcash node and no koganyd.

git clone https://github.com/boyfromcave/kogany
cd kogany && git checkout v1.8.0-ycash.beta2
cargo build --release --locked -p kogany --bin koganyd --features ycash

The integration branch, upgrade/vault, builds the same way and runs ahead of the latest pre-release.

Installing with Cargo

Not available. Kogany is not published to crates.io: its Ycash crates come from a fork pinned by git revision, so build from the tagged source above.
