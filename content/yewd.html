Wallet compatibility

ycashd wallet RPCs

For software that still speaks to ycashd's built-in wallet, yewd serves the same RPCs beside a Kogany node.

Source only, for testing. yewd has no binary release yet. With the Kogany v1.8.0-ycash.beta3 pre-release it is built from source at yew 47898988, the commit its release notes name. For beta2 (yew fc56fba7), sends between every address type, vault locks, mints, YED sends and redeems were run end to end on regtest with Kogany as yewd's node and as the miner.

What it is

yewd is the YEW wallet core run as a daemon. It's the third front end on that core, beside the mobile app and the web wallet. It follows Kogany through the node's RPC, its indexer streams and lightwalletd, and presents the ycashd wallet interface, Yellowback calls included, on its own port.

Why a separate process

It keeps the consensus node small, and the wallet logic is code that already runs in YEW's apps. A separate wallet can fall behind the node, though. So before answering any wallet call, yewd checks that it has caught up with the node's best block and mempool, returns an error instead of stale balances when it hasn't, and rewinds cleanly through reorganizations.

Who uses it

  • YecWallet, the desktop wallet
  • Yellowback price attestors and bridge attestors
  • x402 agent payments, which sign through the node wallet
  • Post-quantum miners, whose block rewards it moves

Post-quantum mining rewards

A block reward paid to a post-quantum address is a coinbase: it can be spent only after 100 blocks, and only to a Sapling address, at the exact amount (the reward less the fee, with no change). Pay such rewards to an address held in a ycashd or yewd wallet, which send it that way with z_sendmany: name any amount, and the refusal names the exact one to send. A YEW app or web address is not suitable: those wallets cannot tell that a coin is a coinbase and cannot make that send.

Already paid at a YEW address? The reward is not lost. Restore the YEW recovery phrase in yewd with -mnemonicfile (a new wallet, which scans from genesis), z_sendmany the exact amount from the post-quantum address to a Sapling address of that wallet, then send it on. The full procedure is in the yewd README.
