Ycash full node · Rust

A Rust node for Ycash, ready for vaults.

Kogany brings Zakura's fast, modern node architecture to the Ycash network and carries the vault upgrade with it.

Kogany is a full node for Ycash. It began as a fork of Zakura, a consensus-compatible Zcash node in Rust. We teach it Ycash's rules: its own branch IDs, Equihash (192,7) and the Ycash Development Fund. Then we add the vault network upgrade.

It is the third node line for the upgrade. The other two are ycashd 4.5 and ycashd 6.20. All three must agree block for block, and Kogany becomes a release line only after it passes that test.

A second codebase checking the first

Two independent implementations of the vault and Yellowback rules, in C++ and in Rust, have to compute the same state hash at every block. If they disagree, a bug has been found before it reaches a real coin.

How the check works

Zakura's sync engine

Kogany inherits Zakura's concurrent block verification, storage and networking. Vault-era blocks are always fully validated: checkpoints never cover them.

What we keep from upstream

A wallet beside the node, not inside it

Like Zakura, Kogany has no built-in wallet. yewd, a daemon built on the YEW wallet core, serves the ycashd wallet RPCs, so YecWallet and the existing tools keep working.

About yewd

Public testnets and a faucet

The fast and slow Yellowback testnets run with free testnet YEC from a rate-limited faucet. Kogany nodes join them once the vault rules are ported.
