Kogany

A Rust full node for Ycash. Built for post-quantum vaults.

Get started Latest pre-release: v1.8.0-ycash.beta2

Kogany is a full node for Ycash, built on Zakura's Rust architecture. It adds Ycash's consensus rules, the vault network upgrade and the Yellowback (YED) rule module.

It is built by the Ycash developers as the third node line beside ycashd 4.5 and 6.20. Meet the team.
