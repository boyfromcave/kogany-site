Ycash Yellowback (YED), a decentralized dollar backed by YEC, will be built on a new network upgrade, not a soft fork. The upgrade adds a general-purpose primitive: vaults, YEC locked under rules every full node enforces, not only miners.

Why a network upgrade

A generic lock-and-release primitive can't be built from Ycash's existing opcodes, and its rules have to be checked by every node to be trusted. So the upgrade gets its own branch ID, 0x6d5b7a31, and activates at a block height, the same way Ycash and Zcash have always upgraded.

What's in it

  • The primitive: vault templates, bonded signer sets with seats, maturity and dormancy, and owner recovery when a set goes quiet.
  • One rule module, YED\0: minting, redemption, claims on undercollateralized positions, attested prices and consensus fee rules.
  • A bridge template for wrapped YEC on Ethereum. Ycash consensus never reads Ethereum.

No activation height is set on mainnet or the public testnets. The heights and the founding attestor set come with the release that passes the upgrade's gates.
