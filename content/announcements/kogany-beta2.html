koganyd v1.8.0-ycash.beta2 is out: Kogany, the Ycash node on Zakura, with the vault network upgrade and the Ycash Yellowback (YED) rule module. Binaries for Linux (x86_64, aarch64) and macOS (Apple silicon) are on the release page; the download page shows how to verify them.

It is a pre-release, for testing. Kogany is not yet a qualified Ycash node line. Run it on the Ycash testnets and expect resyncs and breaking changes between pre-releases. No activation height for the vault upgrade is set on mainnet.

What changed since beta1

  • Ycash's block time bounds. beta1 carried Zcash's bounds and rejected valid Ycash blocks. beta2 enforces Ycash's (10,800 s past the median time of the previous 11 blocks, 14,400 s past the node's clock). It follows the fast testnet through the Vault activation at 510,400 with ycashd's block hashes, and validates mainnet from the Canopy checkpoint to 3,097,335 with ycashd's tip and value pools.
  • Post-quantum addresses name their scheme in the third character (sqf… / sqs… for YEC, ybf… / ybs… for YED on mainnet), and rpcversion is 9.
  • Testnet profiles: "Testnet" is the fast testnet; "TestnetSlow" and "TestnetLegacy" select the two shadow forks of mainnet.
  • Smaller Linux downloads: debug info ships as a separate archive.

The wallet

koganyd has no wallet of its own. yewd is the wallet in front of it, built from source in this wave. The release notes list where it still differs from ycashd's wallet.
